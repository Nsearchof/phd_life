# Research

The actual research work, split by mode:

- **[Theory/](Theory/)** — derivations, symbolic/analytic notes, model-building. Cite sources by wikilink (`[[cite_key]]`). When a step is checked symbolically (SymPy / Mathematica / by hand), record what was run so it reproduces.
- **[Experiments/](Experiments/)** — a dated lab-notebook entry per run/experiment (`YYYY-MM-DD_slug.md`), following [`_template_experiment.md`](Experiments/_template_experiment.md). Raw or large data lives outside git (see [.gitignore](../.gitignore)); the entry records *what* was done and *where* the data is.

Both modes draw on the shared [Literature/](../Literature/) database and feed the deliverables tracked in [Planning/](../Planning/).
